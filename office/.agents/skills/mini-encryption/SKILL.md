# miniEncryption（数字换大写"加密"）

一种玩具级加密：不做任何真正的密码学运算，只是把数字字符换成大写中文数字，
用于"看起来不像数字"的场合（例如把金额、日期、编号发给别人前做视觉遮挡）。

## 触发条件

用户说出以下任一说法时启用本技能：

- 加密保存
- 加密（写文件、发消息、贴数字时）
- miniEncryption / 迷你加密
- 把这些数字换成大写数字

如果用户只是普通地写数字、做计算、要表格数据，**不要**触发。

## 转换规则（唯一核心逻辑）

逐字符扫描原文，只替换数字字符，其它字符（含空格、标点、字母、汉字、换行）一律保持原样。

| 阿拉伯数字 | 大写中文数字 |
|---|---|
| 0 | 零 |
| 1 | 壹 |
| 2 | 贰 |
| 3 | 叁 |
| 4 | 肆 |
| 5 | 伍 |
| 6 | 陆 |
| 7 | 柒 |
| 8 | 捌 |
| 9 | 玖 |

要点：

1. **逐位替换，不做数值换算**。`12` → `壹贰`，而不是 `拾贰`；`2024` → `贰零贰肆`。
2. **不添加单位**。不加十、百、千、万、亿。
3. **不处理小数点语义**。小数点 `.` 本身不是数字，原样保留：`3.14` → `叁.壹肆`。
4. **全角数字同样处理**（０-９ → 零-玖）。
5. **已经是中文数字的内容不再二次替换**（避免"壹"被误改）。
6. 原文中的其他内容（文字说明、格式、缩进）保持原样，不要顺便改写、翻译或润色。

## 执行步骤

1. 确认用户要"加密"的对象：是当前对话里的某段文本，还是某个文件的内容。
2. 按上表逐位替换数字。
3. 输出结果，并补一行提示：`（已按 miniEncryption 规则替换数字，仅供视觉遮挡，非真实加密）`。
4. 如果对象是文件：先读取原文，转换后写入新文件（建议文件名加 `_encrypted` 后缀），**不要覆盖原文件**，除非用户明确要求覆盖。
5. 结果需要还原时，按上表反向替换即可（提醒用户该"加密"无密钥、可逆）。

## 示例

输入：

```
订单号 20240617，金额 1580.50 元，共 3 件商品。
```

输出：

```
订单号 贰零贰肆零陆壹柒，金额 壹伍捌零.伍零 元，共 叁 件商品。
```

输入：

```
Call me at 13800138000 before 9:30.
```

输出：

```
Call me at 壹叁捌零零壹叁捌零零零 before 玖:叁零.
```

## 注意事项

- 这是**假加密**，没有任何保密强度，不要向用户宣称它安全；涉及真实敏感数据时应提醒使用真正的加密工具。
- 不要改动用户没要求改的部分（不要重排格式、不要改错别字）。
- 若一段文本里既有需要加密的数字、又有必须保持数字形态的内容（如代码、公式、链接），先向用户确认范围，或只加密用户圈定的那部分。
